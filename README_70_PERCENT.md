# Student Disengagement Early-Warning System — 70% Phase

This package combines the completed 35% foundation with the next 35% implementation.

## Added in the second 35%
- Streamlit MVP dashboard
- Failure analysis and prediction-confidence output
- Three edge-case evaluations
- Before-vs-after workflow experiment
- Architecture and data schema documentation
- Stakeholder assumptions and validation plan
- Risk register and responsible-use safeguards
- User guide and reproducibility documentation
- Automated pipeline tests
- Complete project report

## Main measured result on the synthetic test set
- Attendance-only baseline F1: 32.81%
- Multi-signal Random Forest F1: 82.18%
- Accuracy: 61.5% -> 88.4%
- Recall: 31.33% -> 89.17%

The dataset is synthetic, so these results demonstrate technical feasibility and the evaluation workflow; they are not evidence of real-world university effectiveness.
