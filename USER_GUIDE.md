# User Guide

## Student Disengagement Early-Warning System

## 1. Purpose

The Student Disengagement Early-Warning System is a prototype designed to identify students who may require additional support by combining multiple learning signals.

The system is intended to support staff decision-making and should not be used for automatic punitive decisions.

---

## 2. System Requirements

The prototype requires:

- Python 3.13 or compatible Python version
- Windows, Linux, or macOS
- Visual Studio Code or another Python-compatible IDE
- Internet connection only for initial package installation

---

## 3. Installation

Open the project folder in Visual Studio Code.

Open the terminal and run:

```text
python -m pip install -r requirements.txt
